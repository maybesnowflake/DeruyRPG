# DeruyRPG 진행 상황

Paper 26.2 / Java 25. 바닐라 무기 9종 RPG 스킬 플러그인. 최신 JAR은 [Releases](https://github.com/maybesnowflake/DeruyRPG/releases) (main 푸시마다 자동 빌드).

## 현재 상태 (2026-11-27)
- 무기 9종 + 공통 코어 완성, CI 빌드 통과
- Codex 리뷰(PR #1) 최종 라운드: 큰 문제 없음
- **인게임 테스트는 아직 안 함** — 아래 "확인 필요" 참고

## 조작
P 패시브 / 우클릭 / 좌클릭 / Shift+우클릭 / F(손 바꾸기) 궁극기.
F는 피버 게이지가 가득일 때만 → 궁극기 + 그 무기에만 피버 15초.

## 명령어 (OP)
| 명령어 | 설명 |
|---|---|
| `/rpg give <무기\|all> [플레이어]` | 무기 지급 (sword, spear, mace, axe, shield, trident, bow, crossbow, rod) |
| `/rpg fever [플레이어]` | 게이지 가득 |
| `/rpg fevercfg [max\|hit\|hurt\|skill\|interval] [값]` | 피버 게이지 설정 보기/변경 (config.yml 저장) |
| `/rpg mana`, `/rpg reset` | 마나 가득, 쿨다운 초기화 |
| `/rpg dummy [clear]` | 훈련봇(피해 숫자 표시) 소환/제거 |

아군 = 같은 `/team`.

## 작업 이력
| 단계 | 내용 |
|---|---|
| 1차 | 스킬 설계 확정(docs/SKILLS.md), 코어(입력·쿨다운·피버·마나·HUD) + 무기 9종 구현 |
| 2차 | 사용자 피드백 개선 + 무기별 피버 능력, 훈련봇, 피버 15초, 폼/모드별 쿨다운 |
| 3차 | 연출 방향(창·도끼 ItemDisplay), 검 막기+패링, 삼지창 차징 급류·찌르기 모션, 낚싯대 좌클릭 전환·마나 부스트(300%/회복 5배), 쇠뇌 화살 4배속, 활 피버 +200%, 방패 성역 강화 |
| 4차 | 1차 독립 리뷰 버그 수정: 무기별 피버, PvP 보호(canHarm), 평타 직후 무적시간, /reload 정리(onDisable), 무기 해제 감지, 재접속 쿨 유지, 메인 스코어보드 팀, 액션바 flash, 삼지창은 03시 결과물로 교체, 방패 24개·2배속·진입 피해 3 |
| 5차 | 피버 게이지·상호작용 롤백 + 게이지 설정화, Codex·2차 Claude 리뷰 반영: 성역 종료 정리·고속 투사체 판정, 넉백 면역 존중(Targets.velocity), 도끼 흡혈 확정 시점, 창 사거리 동기화 최적화, 쿨다운 치른 버프 유지, NaN 방어 |

상세 스킬 명세: [docs/SKILLS.md](SKILLS.md) (1차 + 2차 변경 표).

## 확인 필요 (인게임)
- 창 큰 창·작은 창·병사 창, 도끼 회전/내려찍기, 방패 성역 방패의 **연출 방향** (계산으로만 검증)
- 삼지창 찌르기 모션이 클라이언트에서 실제로 보이는지
- 낚싯대 기본 모드 우클릭 시 모드가 바뀌지 않는지
- 검 막기·패링, 삼지창 차징 급류

## 알려진 선택 사항
- 스킬은 상호작용 블록/엔티티 우클릭·블록 좌클릭에서도 발동 (사용자 결정)
- 벽 너머 판정(시야 검사) 없음, 밸런스는 현재 수치 유지 (사용자 결정)
- 도끼 처형 CC 무시는 구속·공중부양·실명·어둠·멀미·나약함·채굴 피로·기절 전부 막음
- 쇠뇌 피버 보너스는 쏠 때 피버였던 화살에만
