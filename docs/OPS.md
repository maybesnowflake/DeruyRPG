# 서버 운영 메모 (던전)

## 명령어 (/dg)
| 명령 | 누가 | 내용 |
|---|---|---|
| `status` · `vote` · `next` · `leave` | 플레이어 | 상태 · 갈림길 투표 · 비전투 라운드 진행 · 던전 나가기 |
| `start <챕터> [플레이어...]` | 관리자 | 시작 (생략 시 주변 10칸) |
| `list` | 관리자 | 진행 중인 판 전부: 라운드·경과 분·각자 목숨/관전 |
| `stats [판수]` | 관리자 | 최근 판 요약: 클리어율, 평균 시간(목표 15분), 보스전 평균(목표 6분), 평균 사망, 첫 갈림길 선택 |
| `kick <플레이어>` · `tp <플레이어>` | 관리자 | 던전에서 내보내기 · 그 플레이어에게 이동 |
| `stop [플레이어/all]` · `lives <플레이어> <n>` | 관리자 | 강제 종료 · 목숨 조정 |
| `rooms` · `reload` · `setreturn` | 관리자 | 방 템플릿 개수 · dungeon.yml/방 다시 읽기 · 귀환 지점 |

## 판 기록 — plugins/DeruyRPG/runs.csv
한 판 = 한 줄: 날짜, 챕터, 결과(clear/fail/stop), 인원, 총 초, 보스 초, 미니보스 초, 사망 수, 경로, 참가자.
엑셀·구글 시트로 열어서 밸런스 조정 (보스 `health`·`armor`, 몹 웨이브, 상점 가격).

## 장애 대응
- 판 도중 서버가 꺼지면: 던전 월드는 다음 시작 때 초기화되고, 참가자는 **다음 접속 때 원래 게임모드 + 귀환 지점으로 자동 복구**
- 플레이어가 나가면 그 사람만 귀환·복구, 남은 파티는 계속
- 관전 상태로 꼬인 플레이어: `/dg kick <이름>` (던전 중) 또는 `/gamemode survival <이름>`

## 밸런스 조정 (dungeon.yml `balance:`)
몹·보스 인원 보정, 이벤트 확률, 에메랄드 보상, 상점 가격을 코드 수정 없이 조정 → `/dg reload`.
이미 서버에 dungeon.yml 이 있으면 새 `balance:` 섹션이 자동으로 안 들어가므로, jar 안의 dungeon.yml 에서 그 섹션만 복사해 붙여넣기 (없으면 기본값 사용).
보스 체력은 기준 인원(boss-base-players, 기본 4)에 맞춘 값 — 2인이면 0.7배, 6인이면 1.3배.
