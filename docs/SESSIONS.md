# 무기별 세션 프롬프트

새 세션을 열고 아래 블록 하나를 그대로 붙여 넣으면 됩니다.

## 검
```
maybesnowflake/DeruyRPG 레포에서 검(sword) 무기를 구현해줘.
- 먼저 CLAUDE.md 와 docs/SKILLS.md 의 "검" 항목을 읽어
- 브랜치 weapon/sword 에서 작업하고, src/main/java/com/fsixel/deruyrpg/weapons/sword/ 안만 수정해
- 스킬 5개(P/우/좌/⇧우/F) 전부 구현, Java 25로 mvn package 통과 확인
- 끝나면 푸시하고 main 대상 PR 만들어줘 (병합은 하지 마)
```
