# 던전 맵 생성 방식 — 결정용 설계안 (Claude, 2026-11-27)

Fsixel 요구: 마크 구조물(지그소) 시스템 느낌으로 여러 맵(전투 맵은 넉넉히 많이)이 섞여서 생성, 길목·갈림길 많게.
또는 정해진 맵을 계속 쓰기. 더 나은 쪽을 Codex와 상의해 결정.
맵 제작: Fsixel이 Python으로 방을 만든다 (구조물 .nbt 또는 스키매틱으로 내보내기 가능).
현재 진행 시스템: `dungeon/` (라운드 그래프, 목숨, 부활, 투표) — 라운드마다 spawn·points·trigger 좌표 필요.

## 선택지
| | A. 고정 맵 | B. 완전 절차 생성 (블록 단위) | C. 방 템플릿 조립 (지그소식) |
|---|---|---|---|
| 방식 | 한 번 지은 맵, 좌표를 /dg set 으로 저장 | 지형·방을 코드로 생성 | 손으로 만든 방 .nbt 여러 개를 매 판 무작위로 골라 붙임 |
| 다양성 | 낮음 (길 4개 고정) | 높음 | 높음 (방 풀 × 그래프 모양) |
| 퀄리티·연출 | 높음 | 낮음 (마크틱 퀄리티 어려움) | 높음 (방 단위는 손작업) |
| 제작 부담 | 맵 1개 크게 | 코드 매우 큼 | 방 여러 개 + 생성기 중간 |
| 좌표 설정 | 라운드마다 수동 | 자동 | 방 안 표지판 마커로 자동 |

## Claude 추천: C (방 템플릿 조립), 보스방·캠프는 고정 템플릿
- 매 판 그래프(스테이지·라운드·갈림길)를 무작위 생성 → 라운드 종류별 방 풀에서 템플릿 선택 → 전용 던전 월드에 배치
- 방 크기 규격: 셀 48×48 (높이 자유), 문은 셀 가장자리 중앙 4방향 고정 위치 → 회전 0/90/180/270 허용
- 방 사이 연결: 복도 템플릿(직선·꺾임·갈림)도 풀로 섞음 → "길목 많은 느낌"
- 마커 = 방 안 표지판: `[spawn]` `[mob]` `[trigger]` `[boss]` `[shop]` `[door:N/E/S/W]` → 배치 후 읽고 제거
- 갈림길 문: 투표 결과 방향의 문만 열림 (나머지 덩굴 벽), 지나간 방은 그대로
- 풀 규모 목표 (정글 챕터): 전투 12+ / 엘리트 4 / 퍼즐 4 / 상점 3 / 휴식 2 / 이벤트 2 / 복도 6 / 미니보스방 1 / 보스방 1 / 캠프 1
- 무기별 길: 방 템플릿에 태그(`tags: [vertical, water, narrow, open]`) → 길 성향에 맞는 방 위주로 뽑음
- 같은 판에서 같은 템플릿 반복 금지, 최근 판에 나온 템플릿 가중치 ↓
- 판 종료 시 던전 월드 영역 초기화(파티별 구역 분리, 여러 파티 동시 가능)

## 확인받을 점 (Codex)
1. A/B/C 중 이 프로젝트(마크 RPG, 2~6인, 15분 챕터, 1인 맵 제작자)에 맞는 선택과 근거
2. C의 위험: 배치 렉(대형 .nbt 동기 배치), 회전 시 블록 방향, 몹 소환·트리거 좌표, 구역 정리, 여러 파티 동시 진행
3. 그래프 생성 규칙 (길목 수·합류·길이) 제안
4. 빠진 것, 첫 구현 범위(MVP) 추천

## 결정 (Codex 리뷰 반영, 2026-11-27)
**C(방 템플릿 조립)로 간다. 1단계는 "고정 그래프 + 방 무작위 교체".**
- 갈림길 그래프는 `dungeon.yml` 의 라운드 연결 그대로 (검증된 흐름 유지) — 무작위 그래프는 2단계
- 라운드마다 풀에서 방을 매 판 무작위로 뽑아 전용 빈 월드(`deruyrpg_dungeon`)에 배치, 라운드 사이는 텔레포트
- 회전·복도 연결 없음 (2단계). 대신 방 풀을 넉넉하게 → 판마다 다른 맵
- 고정 맵(A)도 계속 지원: 라운드에 `/dg set ... spawn` 하면 그 라운드는 고정 위치

### 구현된 계약
| 항목 | 내용 |
|---|---|
| 템플릿 위치 | `plugins/DeruyRPG/rooms/<풀>/<이름>.nbt` (+ 선택 `<이름>.yml`: `tags: [water]`, `weight: 2`) |
| 풀 이름 | 라운드 `pool` (기본 = type): `camp`, `combat`, `elite`, `puzzle`, `shop`, `rest`, `event`, `miniboss`, `boss` |
| 크기 | 가로·세로 ≤ `room-cell`(64), 높이 ≤ 250 (Y=64에 배치). 바닥 포함해서 저장 (빈 월드라 아래가 허공) |
| 마커 표지판 (첫 줄) | `[spawn]` 필수 1개 · `[mob]` 몹 소환 지점 여러 개 · `[boss]` 보스 소환 · `[trigger]` 퍼즐 완료 지점 |
| `[trigger]` | 표지판 자리가 **레드스톤 램프**로 바뀜 → 퍼즐 회로 출력을 그 자리에 연결, 신호 들어오면 클리어 |
| 배치 | 틱당 6000블록씩 나눠 배치 (렉 방지), 다 놓인 뒤 입장 |
| 선택 규칙 | 라운드 `tags` 와 겹치는 방 가중치 ×3, 같은 판 같은 방 반복 X (후보 부족 시 허용) |
| 정리 | 판 종료 시 구역 엔티티 제거 + 블록 비움 후 구역 반납. 서버 재시작 시 던전 월드 통째로 초기화 |
| 검증 | 시작 전: 풀이 비어 있으면 시작 거부(목록 표시) / 배치 후: `[spawn]` 없는 방 있으면 생성 실패 → 귀환 |
| 기록 | 판마다 어느 라운드에 어떤 방이 쓰였는지 서버 로그 `[던전 N] 방 배치:` |
| 다중 파티 | 파티마다 x 4096칸 떨어진 구역. (스킬 대상 판정의 파티 격리는 아직 거리 분리만 — 2단계) |

### 방 만드는 법 (Python 제작 기준)
1. 방을 짓고 마커 표지판 세우기 (`[spawn]` 은 꼭)
2. 구조물 블록(Save 모드)으로 저장 → `world/generated/minecraft/structures/<이름>.nbt` 를 `rooms/<풀>/` 로 복사
   (또는 Python에서 .nbt 구조물 형식으로 바로 출력)
3. `/dg reload` → `/dg rooms` 로 풀별 개수 확인 → `/dg start jungle`

### 정글 챕터 방 목표 수
camp 1 · combat 12+ (태그 vertical/water/narrow/open 골고루) · elite 4 · puzzle 4 · shop 3 · rest 2 · event 2 · miniboss 1 · boss 1

### 2단계 (나중)
무작위 그래프(DAG: 갈림길 2회 × 2선택, 1~2방 안에 합류, 실패 시 고정 그래프로 폴백) · 복도 템플릿과 문 연결 · 4방향 회전 · 최근 판 가중치 · 파티 격리 판정

## 협곡 연결 (2026-11-27, Fsixel 요청: "주변을 협곡 느낌으로, 걸어서 이어지게")
- 배치: 깊이 = 남쪽(+z), 갈림길 = 동쪽(+x). 칸(`room-cell`) 가운데 정렬, 칸 사이 40칸이 협곡
- `gen/CanyonGen`: 방 바닥판·길을 "열린 곳"으로 두고, 거리 9칸 안쪽 기둥마다 절벽 (거리장 + 노이즈)
  - 길: A `[exit]` → 남쪽 중간 → B 입구(스폰 x). 중심선을 저주파 노이즈로 휘게(방 문 근처는 직선), 폭 잔물결 + 가끔 넓은 웅덩이
  - 절벽: 열린 곳에서 멀수록 높아지는 3칸 계단식 턱(풀), 지층 띠(돌·안산암·응회암·이끼 조약돌·굳은 진흙), 길 쪽 벽에 덩굴
  - 바닥: 거친 흙·이끼·풀·뿌리 흙·진흙 섞기, 풀·고사리, 가끔 돌
- 진행: 라운드 클리어(또는 투표) → 다음 방 입구 앞 이끼 문이 열림 → 살아 있는 파티원이 그 방에 들어서면 라운드 시작 (안에 있는 사람은 그대로, 나머지만 스폰으로). 90초 안에 안 오면 텔레포트
- 같은 깊이·역방향 연결(예: 암시장→성소)은 길 없이 기존 텔레포트
- 정리: 협곡 전체 영역을 판 종료 때 비움 (shortcut: 영역 통째로 훑음 — 느리면 놓은 블록 목록만 지우게 바꿀 것)
- 확인: 로컬 Paper 26.2 서버에서 `/dg start jungle` 생성 → 리전 파일 렌더로 길·문·절벽 확인. 걸어서 진입·문 열림은 인게임 확인 필요
