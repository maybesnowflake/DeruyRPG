# 정글 던전 기획안 v0.4 — "이끼에 잠긴 고대 수문"

기획: Claude (2026-11-27). 맵 지형은 Python으로 별도 제작, 이 문서는 구성·몹·규칙 기획.
보스: `boss/moss-warden` 브랜치의 이끼 수문장 (docs/BOSS.md).

## 확정 사항 (Fsixel)
- **던전형** 일자 진행, 첫 맵 총 **10~20분** (목표 약 16분), 그중 **보스전 약 6분**
- 스테이지마다 **상점 1~2회** (뒤로 갈수록 늘어남) + **퍼즐 요소**
- 몹: 마크 기존 몹 + 장비 착용 + 몹마다 변형, 마크틱한 자체 제작 몹 (정글 우민, 포자 버섯 등)

## 목숨 규칙
- 던전 전체에서 1인당 **목숨 3개를 공유** — 보스전 포함. (예: 일반 스테이지에서 1개 쓰면 보스전엔 2개)
- 일반 스테이지에서 죽으면 목숨 1개 소모 → 그 스테이지 체크포인트에서 부활
- 보스전에서 죽으면 목숨 1개 소모 → **10초 뒤** 보스방 재생성 지점에서 부활
- 개인 목숨 0 → **기본 월드로 귀환** (던전 탈락)
- **전멸** (살아 있는 인원 0, 일반 스테이지·보스전 동일) → 파티 전원 던전 종료, 기본 월드로 귀환
- 목숨은 스테이지 사이에 회복되지 않음 (상점의 "여분 목숨"으로만 회복, 아래 참고)

|---|---|---|---|
| 0 | 무기 거치대 9종, 훈련봇, 팀 발판, 출발 문 | — | 시험용 |

## 퍼즐 (짧게, 각 30~60초)
| 스테이지 | 퍼즐 | 방식 |
|---|---|---|
| 1 | 덩굴 다리 잇기 | 나무 위 덩굴 매듭 3개를 활/쇠뇌로 쏴서 끊으면 다리가 내려옴 (원거리 무기 없으면 올라가서 직접) |
| 2 | 수문 수위 맞추기 | 레버 3개 조합으로 수로 물높이 조절 → 맞으면 잠긴 길이 드러남. 틀리면 익사체 추가 스폰 |
| 3 | 레버 문양 | 벽 문양(이끼 블록 무늬)과 같은 순서로 레버 당기기, 압력판은 동시 2명 이하 |

## 상점 (마크틱하게: 떠돌이 상인/우민 상인 NPC + 거래 창)
- 화폐: 몹 처치 시 떨어지는 **에메랄드** (스테이지가 갈수록 많이 떨어짐)
- 품목 예시: 회복 포션·황금 사과·화살·방어구 수리·버프 포션·**여분 목숨(+1, 1인 1회, 비쌈)**
- 뒤 상점일수록 품목·재고 늘어남

## 보스 — 이끼 수문장 (6분 목표)
- 체력 400 (2페이즈 600) + **방어력 10 / 방어 강도 4** (`boss/moss-warden`에 반영, config `armor`, `armor-toughness`)
- 방어력은 평타·투사체·일반 스킬에 적용, 관통(활 워든 음파)·마법(낚싯대) 피해는 무시 → 무기별 역할 차이
- 6분 맞추기: 인게임 테스트로 `health`·`armor` 조정 (기준 4인)

## 보스방 조건 (BOSS.md 패턴 기준)
- 반지름 ≥ 16칸 평평한 원형, 천장 ≥ 12칸
- 가장자리 얕은 물 링 (삼지창), 기둥 3~4개 (독침 일부 엄폐)
- 전투 시작 시 입구 덩굴 벽으로 봉쇄, 처치 시 열림
- 재생성 지점: 입구 안쪽 (보스 정면 X)

## 인원 보정 (2~6인)
- 기준 인원은 스테이지 시작 시 고정 (사망·탈락으로 안 바뀜)
- 몹 체력은 완만하게 (인원당 +15% 정도), 몹 수·웨이브 크기는 따로 조절
- 보스 체력도 같은 방식

## 플러그인 작업 (추후 `dungeon/` 패키지)
- 던전 입장·종료(기본 월드 귀환), 스테이지 진입·클리어 감지, 문 열기, 체크포인트
- 공유 목숨 3개, 보스전 10초 재생성, 개인 탈락·전멸 처리
- 몹 스폰 웨이브 + 커스텀 몹 (PDC 태그, 바닐라 엔티티 + 장비 + 리스너)
- 상점 NPC (거래 창), 에메랄드 드롭, 퍼즐 판정 (레버·압력판·수위)
- 맵 좌표는 config에 스테이지별 저장 (`/rpg dungeon set ...`)
