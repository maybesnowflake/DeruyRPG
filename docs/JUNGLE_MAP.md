# 정글 던전 기획안 v0.3 — "이끼에 잠긴 고대 수문"

기획: Claude (2026-11-27). 맵 지형은 Python으로 별도 제작, 이 문서는 구성·몹·규칙 기획.
보스: `boss/moss-warden` 브랜치의 이끼 수문장 (docs/BOSS.md).

## 확정 사항 (Fsixel)
- **던전형** 일자 진행 (스테이지 → 스테이지)
- 몹: 마크 기존 몹 + 장비 착용 + 몹마다 변형. 마크틱한 자체 제작 몹도 추가 (예: 정글 우민, 얼음 크리퍼)
- 목숨 규칙
  - 일반 스테이지: 모두 목숨 3개. 다 잃으면 관전 → **다음 스테이지 시작 때 부활**
  - 보스전: 죽으면 **10초 뒤 보스방에서 재생성** (목숨 무관)
  - 목숨은 다음 스테이지 진입 시 3개로 초기화
- 전멸 규칙 (Codex 리뷰 반영)
  - 일반 스테이지 전원 목숨 0 → **현재 스테이지 재시작**: 전원 3목숨 복구, 그 구간 몹·퍼즐·문 초기화, 이미 연 보상 상자는 재지급 안 함
  - 보스전 전원 동시 사망 → 보스 체력·졸개·진행 중 패턴 초기화, 입구에서 함께 재도전 (개인 10초 재생성은 유지)

## 보스방 조건 (BOSS.md 패턴 기준)
- 반지름 ≥ 16칸 평평한 원형, 천장 ≥ 12칸
- 가장자리 얕은 물 링 (삼지창), 기둥 3~4개 (독침 일부 엄폐)
- 전투 시작 시 입구 덩굴 벽으로 봉쇄, 처치 시 열림
- 재생성 지점: 입구 안쪽 (보스 정면 X)

## 플러그인 작업 (추후 `dungeon/` 패키지)
- 스테이지 진입·클리어 감지, 문 열기, 체크포인트
- 목숨 관리 (3개, 관전, 다음 스테이지 부활, 보스전 10초 재생성)
- 몹 스폰 웨이브 + 커스텀 몹 (PDC 태그로 식별, 바닐라 엔티티 + 장비 + 리스너)
- 맵 좌표는 config에 스테이지별 저장 (`/rpg dungeon set ...`)

## 인원 보정 (2~6인)
- 기준 인원은 스테이지 시작 시 고정 (사망·재생성으로 안 바뀜)
- 몹 체력은 완만하게 (인원당 +15% 정도), 몹 수·동시 압박(웨이브 크기)은 따로 조절
- 보스 체력도 같은 방식 (`boss.moss-warden.health` 기준 × 보정)
