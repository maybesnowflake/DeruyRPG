# 야간 통합 점검 최종 조치

기준: origin/feature/dungeon-content d8cda6d, codex/overnight-completion.

## 최종 수정 2건

1. `/dg start jungle A A`의 중복 참가자를 시작 단계에서 제거해 참가자·생존 인원·체력 배율·전멸 판정이 중복되지 않게 함.
2. 던전 생성 중 round가 null일 때 사망 대체 경로가 `down()`에서 NPE를 내지 않도록 방어함. 생성 중에는 목숨을 차감하지 않음.

## 독립 검토로 제외한 수정

초기 Claude Sonnet 검토는 정글 주술사의 벡스 잔류를 수정 후보로 올렸지만 `DungeonMobs.onVex`에 이미 소환 차단이 있음. 최종 소스에는 벡스 주변 삭제나 새 소유권 태깅을 추가하지 않음. 불필요한 삭제 범위·보상 변경을 피하기 위해 기존 동작을 유지함. 최초 검토 결과를 최종 구현 사실로 보고하지 않음.

## 검사

- Java25 / Maven3.9.11 package 성공.
- 방 30개 생성 strict 검사, 퍼즐 회로 5개 모두 통과.
- 별도 실제 Paper26.2-135 서버의 QA 플러그인으로 참가자 중복 제거, 같은 사람 재시작 거절, 생성 중 사망 무예외·목숨 유지 검증 통과. 참가자는 Java Proxy이며 실제 접속 플레이어 테스트가 아님.
- 전체 런타임 검사 결과와 구체적 미검증 범위는 별도 rpg-qa 보고서 참조. 실제 사람의 보스 회피·무기 조작·다중 접속은 미검증.
