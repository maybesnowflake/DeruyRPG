# 일반 모드 기획 초안 v0.1 — 마크 서버용 (Claude, 2026-11-28)

게임 = **던전**(챕터 > 스테이지 > 라운드) / **일반**. 일반 = 던전 밖에서 서버 플레이어가 평소에 지내는 모드.
목표: 던전에 들어갈 이유(준비·성장·자랑)를 만들고, 던전 사이 시간을 채우는 마크다운 서버 생활.

## 방향 선택지
| | A. 서바이벌 RPG | B. 로비 허브 | C. 허브 + 야생 (추천) |
|---|---|---|---|
| 구성 | 야생 월드 하나에 무기 스킬·던전 입구 | 마을 로비에서 던전·미니게임 대기열만 | 마을 허브(상점·대장간·퀘스트·던전 포탈) + 자원용 야생 월드 |
| 장점 | 가장 마크틱, 자유도 | 관리 쉬움, 던전 집중 | 둘의 장점, 역할 분리 |
| 단점 | 경제·그리핑 관리 부담 | 할 게 적어 접속 이유 약함 | 제작량 가장 많음 |

**추천 C** — 허브는 고정(운영자가 관리), 야생은 주기적 초기화 가능. 던전 = 핵심 콘텐츠, 일반 = 준비·성장·사교.

## 핵심 루프
야생에서 자원 → 허브 대장간에서 무기 강화·의뢰 → 파티 모집 → 던전 → 보상(재료·칭호·기록) → 다시 강화

## 시스템 (우선순위 순)
| # | 시스템 | 내용 | 기존 코드 재사용 |
|---|---|---|---|
| 1 | **무기 숙련도** | 무기별 경험치(일반·던전 처치) → 레벨 1~10. 레벨마다 작은 보너스(피해 +1%) + 5·10레벨에 스킬 변형 해금 | 무기 9종·`Items.kitId` |
| 2 | **파티** | `/party` 초대·수락, 파티 채팅, 파티장이 `/dg start` (주변 10칸 대신 파티 기준) | 던전 `start(players)` |
| 3 | **허브** | 마을: 던전 포탈(챕터 선택), 대장간 NPC(강화), 의뢰 게시판, 기록 비석(랭킹) | 상인 NPC·거래 창 |
| 4 | **의뢰 (일일·주간)** | "철퇴로 몹 30마리", "정글 챕터 15분 안에 클리어" 등 → 보상: 강화 재료·칭호 | `runs.csv` 기록 |
| 5 | **랭킹·칭호** | 챕터별 최단 클리어, 무사망 클리어, 숙련도 10 — 허브 비석 + 탭 리스트 칭호 | RunLog |
| 6 | **필드 이벤트** | 야생에 정해진 시간 "이끼 수문장 원정"(서버 전체 레이드, 보스 재사용) | MossWarden + 인원 보정 |
| 7 | PvP 구역 (선택) | 허브 투기장만, 무기 스킬 PvP 밸런스 별도 | — |

## 경제 (결정 필요)
- 현재 던전 에메랄드는 진짜 아이템 → 던전 밖으로 들고 나올 수 있음 (인플레이션 위험)
- 안 ① 던전 전용 화폐로 분리 ("이끼 결정", 판 끝나면 소멸) — 던전 상점 밸런스가 안 깨짐 **(추천)**
- 안 ② 에메랄드 공용 — 단순하지만 야생 주민 거래로 무한 수급 가능
- 일반 화폐는 에메랄드 그대로(주민 거래 마크틱), 던전 클리어 보상은 "강화 재료"로 지급

## 운영 (서버용)
- 역할: 운영자 / 빌더(허브 편집) / 일반 — 권한은 LuckPerms 그룹으로
- 허브 보호(블록 변경 금지), 야생 초기화 주기(시즌), 백업 주기
- 운영 기록: runs.csv + 숙련도·의뢰 데이터는 플레이어별 YAML 또는 SQLite
