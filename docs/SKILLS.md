# DeruyRPG 스킬표 (확정본)

입력: **P** 패시브 / **우** 우클릭 / **좌** 좌클릭 / **⇧우** Shift+우클릭 / **F** 손 바꾸기(궁극기)

공통 규칙
- F는 피버 게이지(때리면 +5, 맞으면 +2, 최대 100)가 가득일 때만 사용 가능. 사용하면 궁극기 + 피버 상태(기본 6초) — 피버 중 스킬 쿨다운 절반.
- 게이지가 가득 차면 무기가 반짝이고 소리가 남. 게이지·쿨다운은 액션바에 표시.
- 마나는 경험치 바에 표시(실제 경험치는 안 건드림). 낚싯대·방패만 사용.
- 아군 = 같은 스코어보드 팀(/team).
- 연출은 바닐라 파티클·사운드·엔티티만 사용 (마크틱하게).
- 수치는 근사값. 구현하면서 밸런스 조정 가능.

## 검 `sword`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 연속 베기 | 3타마다 휩쓸기 강화 + 공격 속도·피해 조금씩 증가 (최대 4회 중첩) |
| 우 | 막기 / 패링 | 우클릭 유지 시 정면 피해 감소. 피격 직전 0.25초 안에 막으면 패링 (상대 구속 + 모루 소리) |
| 좌 | 휩쓸기 베기 | 평타 |
| ⇧우 | 돌진 베기 | 2.5칸 전방 대시, 경로의 적 휩쓸기 |
| F | 일섬 | 잠깐 멈췄다가 전방 8칸 일직선 베기 (크리티컬 파티클) |

## 창 `spear`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 긴 창 | 리치 +2칸. 나와 2칸 이내 적을 때리면 추가 피해 |
| 우 | 연속 찌르기 | 빠르게 여러 번 찌르기 |
| 좌 | 찌르기 | 평타 |
| ⇧우 | 큰 창 찌르기 | 큰 창으로 전방 3×5 범위 관통 찌르기 |
| F | 고대 군단 | 양옆에 병사 5~7명(마네킹/갑옷 거치대 + 창)이 일렬로 서서 돌진 — 경로의 적을 밀쳐내고 피해, 이후 각 병사가 연속 찌르기 |

## 철퇴 `mace`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 낙하 강타 | 낙하 거리 비례 추가 피해 (상한 20칸) |
| 우 | 도약 강타 | 위로 뛰어올라 착지 시 범위 피해 (피해 약간 낮게) |
| 좌 | 강타 | 평타 |
| ⇧우 | 돌풍 | 공중에서 한 번 더 점프 (Wind Burst) |
| F | 지진 | 착지 지점 주변 블록이 FallingBlock으로 튀어오르며 적을 띄움 |
- 갑옷 파쇄는 인챈트로 분리

## 도끼 `axe` (광전사)
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 광폭화 | 체력이 낮을수록 공격력·공격 속도 증가 (30% 이하 최대) |
| 우 | 회전 베기 | 4×4 범위 + 방패 무력화. 내 체력 1칸 소모 |
| 좌 | 내려찍기 | 평타. 피해 일부만큼 체력 회복 |
| ⇧우 | 피의 도끼 | 전방 적에게 추가 출혈 피해(도트, 레드스톤 파티클) + 나에게 힘 II 5초 |
| F | 처형 | 체력 20% 이하 적 처형 + 나에게 힘 + CC 무시(구속·공중부양·넉백 면역) |

## 방패 `shield` (탱커)
주손에 방패를 들고 사용. 좌클릭으로 방패 ↔ 불사의 토템 스왑.

| 키 | 방패 폼 | 불토 폼 |
|---|---|---|
| 좌 | 불토로 스왑 | 방패로 스왑 |
| P | 철벽: 막은 피해 일부 반사, 막는 중 넉백 면역 | 들고 있으면 재생. 1회 부활 |
| 우 | 막기 | 나에게만 재생 |
| ⇧우 | 넉백 + 짧은 구속 | 아군 체력 3칸 즉시 회복 + 마나 10% 회복 |

F – 성역 (폼 무관)
- 반경 4칸 방패 돔, 8초
- 돔 안으로 들어오는 투사체 전부 차단
- 돔 안에서 죽은 아군 부활 (궁극기 1회당 최대 2회)
- 불토 P(1회 부활) 재충전
- 나에게 흡수 + 저항 I + 저지불가 + 발광 + 구속(느려짐)
- 7칸 안의 적에게 실명 (발광 때문에 나만 보임)

## 삼지창 `trident`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 물의 가호 | 나 또는 적이 물에 닿아 있으면 추가 피해, 물속 공격 속도 증가, 물보라 이펙트 |
| 우 | 투척 / 급류 | 급류 인챈트 있으면 급류, 없으면 투척 (바닐라 규칙). 투척은 탄퍼짐 없이 직진 |
| 좌 | 찌르기 | 사거리 4칸 평타. **비 속에서는 물살 찌르기** (6칸 일렬 관통 물줄기) |
| ⇧우 | 물기둥 | 전방에 물기둥(거품 기둥)을 세워 적을 위로 띄움 |
| F | 뇌우 + 비 소환 | 일정 시간 내 주변에 비가 계속 내리고 주변 적에게 번개. 나는 항상 젖은 상태 → 물의 가호 유지 |
- 참고: TridentPlus 인챈트 설계 (찌르기형 날카로움·밀치기 / 투척형 임페일링·펀치, 채널링 날씨별 확률)

## 활 `bow`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 풀차지 | 풀차지 사격 시 피해 +25% |
| 우 | 사격 | 바닐라 |
| 좌 | 발차기 | 근접 적 넉백 (거리 벌리기) |
| ⇧우 | 폭발 화살 | 다음 3발이 폭발 화살 |
| F | 워든 음파 | 전방 직선 Sonic Boom, 방어력 일정 무시 |

## 쇠뇌 `crossbow`
| 키 | 스킬 | 내용 |
|---|---|---|
| P | 직진 탄도 | 화살이 탄퍼짐 없이 직진 |
| 우 | 사격 | 바닐라 |
| 좌 | 발차기 | 근접 적 넉백 |
| ⇧우 | 구속 화살 | 10초 동안 쏘는 화살에 구속 부여 |
| F | 유도 연사 | 화살이 적을 유도 + 고속 연사 |
- 다중발사·관통·폭발은 인챈트로 분리

## 낚싯대 `rod` (마법사)
우클릭으로 모드 변경: 기본 → 당근 → 균. 손의 아이템도 낚싯대 / 당근 낚싯대 / 뒤틀린 균 낚싯대로 실제로 바뀜.

| 모드 | 좌 (단일) | ⇧우 (범위) |
|---|---|---|
| 기본 | 찌로 적 끌어오기 | 이보커 송곳니 일렬 소환 |
| 당근 | 아군 신속 + 재생 | 주변 아군 힘 + 저항 |
| 균 | 적 구속 + 나약함 | 디버프 장판 (어둠 + 발광) |

- P: 경험치 바 = 마나
- F – 대마법: 적을 한곳으로 끌어모은 뒤 여러 색 파티클과 함께 송곳니 + 위더 + 독 + 나약함
