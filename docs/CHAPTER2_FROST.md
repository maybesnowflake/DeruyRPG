## 새 시스템: 체온 (챕터 2 한정)
- 화면 액션바 눈금 0~100. 추운 구역(눈보라·얼음물)에서 감소, 모닥불·휴식·용암 근처에서 회복
- 50 아래: 신속↓ / 20 아래: 바닐라 "얼어붙음"(분말눈 효과) 연출 + 초당 약한 피해
- 공략 포인트: 라운드 사이 모닥불 위치 선택, 상점 "따뜻한 수프"(체온 +40), 유물 "불씨 부적"
- 외형으로 규칙 알려주기: 추운 구역은 눈 입자·푸른 화면 가장자리, 따뜻한 곳은 모닥불 연기

## 스테이지 구성 (갈림길 그래프는 정글과 같은 방식)
| 스테이지 | 구성 | 시간 |
|---|---|---|
| 1 설원 기슭 | 캠프 → 무기별 길 4개 (라운드 4) | 6분 |
| 2 빙하 동굴 | 갈림길 2회, 휴식·암시장, 끝에 **미니보스 "서리 수호자"** (최종 보스 1페이즈, 능력치 75%) | 7분 |
| 3 얼음 왕관 | 라운드 2 → 보스 전 상점 → **최종 보스 "서리 수호자"** (1페이즈 → 각성 → 2페이즈) | 9분 (보스 7분) |

### 무기별 시작 길 (특기 무기 지형 보너스)
| 길 | 지형 | 유리한 무기 | 없을 때 대안 |
|---|---|---|---|
| 빙벽 오르막 | 얼음 절벽·고드름 | 철퇴(낙하로 고드름 깨 지름길), 활·쇠뇌(고드름 쏴서 떨어뜨림) | 돌아가는 계단 |
| 얼음 호수 | 얇은 얼음·얼음물 | 삼지창(물속 급류, 얼음 깨고 잠수 루트), 낚싯대(당겨 건너기) | 얼음 위로 우회 (금 가는 얼음 주의) |
| 눈사태 협곡 | 좁은 협곡, 굴러오는 눈덩이 | 방패(눈덩이 막기), 창(직선 관통), 검 | 바위 뒤 숨으며 이동 |
| 설원 사냥터 | 넓은 눈밭, 몹 떼 | 도끼(흡혈·회전), 검 | 전투가 길어짐 |

## 몹 (바닐라 기반 + 장비 + 변형, 위험 행동은 예고 후)
| 이름 | 기반 | 변형 |
|---|---|---|
| **얼음 크리퍼** | 크리퍼 | 폭발 대신 서리 폭발 — 블록 파괴 X, 반경 3 구속+체온 -25, 불 꺼짐. 하늘색 입자로 예고 |
| 서리 해골 | 스트레이 | 둔화 화살 + 가죽 모자(하늘색), 높은 곳 배치 |
| 눈보라 정령 | 브리즈 | 바람 돌격 대신 눈보라 돌풍(밀쳐내기 + 체온 -10) |
| 얼음 거미 | 동굴 거미 | 독 대신 구속, 천장에서 내려옴(덩굴 소리 대신 얼음 깨지는 소리 예고) |
| 동굴 북극곰 | 북극곰 | 일어서기(1초 예고) → 앞발 내려찍기 범위 |
| 서리 우민 | 변명자·약탈자 | 정글 우민의 겨울 버전 (털가죽 장비, 쇠뇌에 둔화 화살) |
| 눈사람 포병 (엘리트) | 눈골렘 | 적대화 — 큰 눈덩이 포격(낙하 지점 그림자 예고), 체력 높음 |
| 얼음 마녀 (엘리트) | 마녀 | 아군 몹에 얼음 갑옷(흡수), 바닥에 얼음판 생성(미끄러짐) |

## 보스: 서리 수호자 (이끼 수문장과 대칭되는 2페이즈 구조)
- 1페이즈: 얼음 갑옷 입은 거인 — 내려치기(원 예고, 착지 직전 빨강), 고드름 낙하(그림자 예고, 사이 안전 칸), 얼음판 미끄럼 돌진(직선 예고)
- 50% 각성: 갑옷이 깨지며 "진짜 모습" (보스 복선 회수 — 미니보스 때 승리음의 변주)
- 2페이즈: 눈보라 장판(체온 압박, 모닥불 기둥 4개가 안전지대 — 1개씩 꺼짐), 얼음 감옥(플레이어 1명 가둠 → 파티가 깨서 구출, 협동 기믹)
- 보스방 조건: 반경 ≥ 16 평지, 천장 ≥ 14, 모닥불 기둥 4개(꺼졌다 켜짐), 가장자리 얼음물 링(삼지창)
- 판정·가독성: docs/BOSS.md "공격 가독성 표" 형식으로 제작 시 작성 (예고 동작/화면 범위/실제 범위/피해 시작 틱)

## 상점·유물 추가 (챕터 2)
- 상점: 따뜻한 수프(체온 +40), 불 저항 대신 "방한 망토"(체온 감소 -30%, 이번 판)
- 유물: 불씨 부적(모닥불 회복 2배 + 체온 20 아래로 안 떨어짐 10초, 60초마다) · 얼음 송곳(근접 공격 시 적 둔화 누적 3회면 1초 빙결)
- 특별 이벤트: "조난된 등반가" — 눈사태가 오기 전 30초 안에 밧줄 레버 3개 당기기
